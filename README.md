# SPK Seleksi Atlet (Lovable UI)

Sistem Pendukung Keputusan (SPK) untuk seleksi atlet kriket berbasis web, menggunakan pendekatan:

- Klasifikasi dengan Decision Tree (C4.5)
- Perangkingan menggunakan AHP-SAW
- Visualisasi performa dengan Radar Chart
- Antarmuka pengguna Lovable UI (HTML + TailwindCSS)

## 📂 Fitur

- 🔐 Login Role (Atlet, Admin, Konsultan)
- 🧠 Simulasi AHP & penyesuaian bobot
- 🏅 Klasifikasi status atlet dan ranking otomatis
- 📈 Visualisasi grafik Spider (Chart.js)
- 🌐 Responsive Web (deployable di GitHub Pages)

## 🚀 Cara Jalankan

1. Upload seluruh file ke GitHub repository
2. Aktifkan GitHub Pages (Settings > Pages > Source: `main`)
3. Akses website dari URL seperti `https://<username>.github.io/<repo-name>/`
